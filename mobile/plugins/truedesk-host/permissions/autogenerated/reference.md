## Default Permission

Lets the app's own UI share this device: check readiness, start and stop hosting, answer the allow/deny prompt and read host events.

#### This default permission set includes the following:

- `allow-host-state`
- `allow-open-accessibility-settings`
- `allow-start-hosting`
- `allow-stop-hosting`
- `allow-answer-request`
- `allow-poll-event`
